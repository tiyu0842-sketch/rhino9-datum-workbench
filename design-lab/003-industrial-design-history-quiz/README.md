## 2. 原理

复习类工具的关键不是"题多"，是**答错之后能真正学会**。所以本项目定四条：

1. **可追溯**：每题带 evidence，答错显示原文片段 + 来源文件名。没有原文的题不出。
2. **不编造**：构建时强制校验 evidence 前 12 字必须在源文件中命中，否则拒绝出题。
3. **确定性**：题目顺序用日期偏移的固定步长算（不用随机），同一天打开题目一致。
4. **错题即教学**（v2）：答错自动弹出科普卡，一张卡只讲一个 idea ——
   生活画面 → 一个问题 → 一句话结论 → 原文锚点 → 可点开的外部来源。
   这是从 3Blue1Brown 风格 SPEC 借来的降认知负荷规则：一次只引入一个新对象、先图像后命名、
   每章只回答一个问题、结尾只收束一个点。**超预算就重写，不堆术语**。

**间隔重复（艾宾浩斯）**：答对后按 `1 → 2 → 4 → 7 → 15 → 30` 天推进阶梯；
答错退回第 0 阶、次日重来。"今日复习"模式只列出到期题。

**技术选择**：单文件 HTML 而非微信小程序。理由：无需开发者工具编译、可直接双击打开、
方便你把题目文本拿去校对、离线可用、改动只是重新生成一个文件。

## 8. 小程序 / 备案 / 微信分享调查结论（2026-11-24，政策会变，复用前复查）

**核心认知**：排行榜要多人可比 → 必须有后端；本地 HTML 只能做个人最佳。

| | 单文件 HTML（现在） | 微信内 H5 | 微信小程序 |
|---|---|---|---|
| 真排行榜 | ❌ 只能本地 | ✅ 需后端 | ✅ 需后端 |
| 备案 | 不涉及 | **域名必须 ICP 备案 + HTTPS** | **必须小程序备案，无例外** |
| 周期 | 0 | 备案 1–20 工作日 | 备案 1–20 工作日 + 审核 1–7 天 |
| 个人主体 | — | 可（域名要备案） | ✅ 可，但**只能免费、非经营性** |
| 分享 | 发文件 | 链接转发，卡片样式需公众号 JS-SDK | 原生小程序卡片，最好 |
| 成本 | 0 | 域名+服务器（约几十元/年起） | 认证 300 元/年（个人可免认证但功能受限） |

**小程序备案五步**：填信息 → 平台初审（1–2 工作日）→ **工信部 12381 短信核验
（24 h 内必须完成，超时自动驳回）** → 通管局审核（1–20 工作日）→ 下发备案号。
纯本地存储的小程序不用域名备案，但**小程序备案本身必须做**。

**大坑**：答题/科普很容易被归到「教育」类目 → 要办学许可证，个人基本拿不到。
实操按「**工具**」类目提审（本质是随机出题 + 自动判题，工具属性 > 教学属性），
无资质要求、过审最稳。个人主体不能做付费/会员/商城。

**H5 微信内分享**：域名必须 ICP 备案 + HTTPS，否则微信限制共享频率甚至拦截；
分享卡片要标题+缩略图需绑定公众号并配 JS-SDK 安全域名。

**结论**：当前目标是自己复习 → 单文件 HTML 够用，不需要小程序/备案。
要"朋友一起刷"时优先用平台托管的 H5（域名通常已备案，省自己备案），再考虑小程序。
题库补到 60–100 题、确认长期运营前，不为一支 11 题的题库折腾 20 天备案。

来源：WebSearch（微信小程序备案官方指引 / 个人主体类目要求 / 微信 H5 分享限制，2026-11 近半年）。

## 9. v3 · 世界线叙事重构（2026-11-24 晚，产品重心转移）

**这是纠偏，不是加功能**。之前 v1/v2 以题为中心（刷题 + 错题科普补丁）；
用户指出真正要的是**先理解一条贯穿的思想演变线，刷题只是巩固**。所以 v3 重建信息架构。

### 9.1 主线（整个设计史想通的一句话）

> **问：机器能批量造东西以后，东西到底该做成什么样？**
> 答：设计史就是一代代人回答这个问题、答案又被下一代推翻的历史。

用三组张力贯穿全程：**装饰↔功能 / 反机器↔用机器 / 精英↔大众**。
11 站因果链（每站回答同一个问题、下一站因上一站答案出问题而转向）：

| 站 | 年代 | 答案（思想） | 转向原因 |
|---|---|---|---|
| 手工艺 | —1750 | 造物为用，装饰与功能同体 | 起点 |
| 文艺复兴 | 14—17C | 从神转向人（人文主义） | 「为谁做」→ 为人 |
| 巴洛克→洛可可 | 1600—1800 | 装饰狂欢，权力广告 | 表现人→炫耀人，装饰走到头 |
| 新古典 | 1760—1820 | 庞贝挖出，回到理性秩序 | 装饰过剩，首次往回撤 |
| 工业革命·水晶宫 | 1851 | 机器能造，但造得丑 | 问题换了：机器造的算不算设计 |
| 工艺美术 | 1850—1914 | 躲开机器，回到手工 | 工业品粗陋 → 第一份答案 |
| 新艺术 | 1890—1910 | 用艺术给工业品整容 | 手工太贵，想折中 |
| **包豪斯** | 1919—1933 | **拥抱机器，为大众设计** | **最大转向**：态度反转 |
| 现代主义 | 1918—1960 | 少即是多，功能主义 | 推到极端 → 千篇一律 |
| 后现代 | 1970—1990 | 少即乏味，人要回来 | 反叛「少」，文脉/戏谑 |
| 当代 | 1990—今 | 为人、为地球负责 | 从风格游戏回到责任 |

### 9.2 幽默锚点 —— 诚实分两类

用户要「幽默的历史/笑话帮助记」。做法：**真实轶事 7 站**（联网核实、可点来源），
**记忆画面 4 站**（为记忆构造的画面，界面明确标「非史实」）。绝不把编的当史实。

真料举例：
- **水晶宫**：245 个建筑师方案全落选，赢家是**花匠**帕克斯顿——受王莲叶脉启发（7 岁女儿能站叶上），
  9 天出草图、9 个月建成；被嘲「不过是个大花房」，却成现代建筑先驱；1936 年烧毁，丘吉尔称「一个时代的终结」。
- **包豪斯**：格罗皮乌斯把 Hausbau 倒拼成 Bauhaus 划清界限；办公室连椅子都是立方体；
  学生亚伯斯买不起材料，上街捡破酒瓶碎玻璃做艺术（「哥不是逃学，是找灵感」）。
- **后现代**：文丘里把密斯的「少即是多」改成「**少即乏味**」(Less is a bore)，
  给妈妈盖的房子像儿童画，被称「20 世纪后半叶最大的小建筑」，还写《向拉斯维加斯学习》。
- **现代主义**：拉姆斯补刀「Less, but better（少却更好）」→ 苹果/MUJI 都受其影响。

### 9.3 信息架构（题是配角）

### 10.2 同类产品对标（先看别人怎么做，再决定自己做什么）

| 产品 / 站点 | 它最强的地方 | 我们借鉴了什么 | 我们明确不做 |
|---|---|---|---|
| **Design Is History**（designishistory.com） | 极简时间轴 + 设计师头像矩阵，视觉优先、文字极省 | 站点卡默认只露「年代 + 3 张缩略图 + 一句钩子」，细节点开才展开 | 不做纯图墙：考研要的是可复述的因果，不是认脸 |
| **刷刷题 / 织岸艺术设计 / 艺术史讲明白**（小程序） | 刷题闭环最完整：章节练习、真题、错题本、艾宾浩斯、模拟考、主观题、正确率统计 | 错题本、SRS（1/2/4/7/15/30）、组卷 20 题、分章正确率、名词解释/简答自评、每日一练 | 不做账号、班级、付费、题库导入（离线单文件，隐私与零部署优先） |
| **中国工艺美术史（智慧教育平台 / 中国大学 MOOC）** | 按**材料门类**组织：陶瓷 / 玉器 / 金属 / 漆器 / 家具 / 建筑，每章带检测 | 时间线加了「门类」筛选（陶瓷 / 家具 / 青铜·漆·玉 / 现代主义 / 当代），一章一测 | 不改主线为门类：门类是索引，年代才是因果 |
| **Anki / Quizlet** | 间隔重复 + 主动回忆，卡片短、翻面快 | 卡片正面只给「图 + 名字」，翻面才给年代与要点；「记住了 / 再看看」写入掌握度 | 不做万能卡组：卡片由时间线自动生成，避免内容与叙事脱节 |
| **Google Arts & Culture** | 高清可缩放藏品 + 主题故事线 | 作品详情做成「大图 + 材料/年代/作者 + 为什么重要」 | 不用外链图片：版权与离线可用性都不可控，改手绘线描 |

**三条结论（也是这一版的设计原则）**：
1. 时间线负责「为什么变」，卡片负责「记住谁」，题库负责「能不能复述」——三者不能互相替代，所以做成三入口而非一个列表。
2. 竞品的强项几乎都在「复习机制」，弱项都在「因果叙事」；我们把机制搬过来，把叙事做厚。
3. 凡是需要账号/联网/版权素材的能力，一律降级为本地实现，保证双击就能用。

### 10.3 核心交互（已实测）

- **大时间线**：27 站按年代并置，红点=世界、绿点=中国；每站可展开「历史背景 / 代表作品 / 人物 / 小故事 / 趣味事件 / 它留下了什么」，并给一条「同期另一条线上」的跳转。
- **搜索 + 门类**：`家具` 命中 11 站并自动展开第一条；`汝窑` 命中 1 站。搜索先匹配名称/作品/人物，命中不足 3 条才回退正文，避免「背景里顺带提一句」的噪声。
- **卡片模式**：范围（全部/中国/世界/本节）→ 抽 10 张（未看过的优先）→ 翻面 →「记住了 / 再看看」→ **第 10 张结束自动弹出该组相关测验 5 题** → 组结算。
- **独立题库**：刷题（即时解析）/ 组卷测验（20 题、交卷统一批改、逐题解析、答题卡）/ 院校高频 / 错题本；名词解释与简答走「评分要点 + 自评」。
- **我的**：累计答题、总正确率、题库覆盖、卡片已看、连续天数、分章正确率、最近测验。
- 深链：`design-history.html?open=w10` 直达包豪斯站；`#bank`、`#cards`、`#me` 直切模块。

### 10.4 数据与诚实边界

- **院校标签 = 高频考区，不是逐字真题**。依据是这些考点在公开教材、考纲与考研回忆版中的重复出现频次；不编造「某校某年」的年份。界面与题库说明里都写了这一条。
- **轶事分两类**：「有据」与「记忆画面」逐条标注；有据的也只写到「学界主流说法」，不假装有档案原文。
- **图示是形体记号，不是文物复原**：43 个 SVG 线描，用于认器形/认结构，比例不追考古精度。
- **题库覆盖**：104 题 / 8 章；中国陶瓷 21、中国家具 14、中国工艺 10、中国近现代 6、外国古代 12、外国近现代 17、现代主义 12、战后与当代 12（含重复计数的多选与主观题）。
- 仍需补的：包豪斯之后的主观题深度、更多院校的题型差异、扫描版资料的 OCR（当前只吃得到文字层）。
