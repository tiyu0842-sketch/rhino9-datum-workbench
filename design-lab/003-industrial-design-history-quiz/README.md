# 003 · 工业设计史每日闯关

> **v2 交付：`quiz_v2.html`** —— 单文件、离线可用、进度存本地。
> 三个模式（每日闯关 / 今日复习 / 错题重做）+ 艾宾浩斯间隔重复 + 双风格切换 + 错题科普卡。
> 题库来自本机 `D:/学习进步资料/工业设计史/` 的 DOC 资料，**每题可核对原文**。

## 1. 想法原话

> 「你调度百度网盘，然后搜索工业设计史，我里面有很多工业设计史的资料，
> 我想把那个设计成一些……类似于答题每日答题闯关的一些小程序，这样的话有助于去复习和温习」

> 追加（2026-11-24 下午）：「出一些闯关的东西，做一个艾宾浩斯遗忘曲线，
> 错题纠正风格切换，可以有一个 Hello Kitty 风格吗……我想要简约风格的，可以切换，
> 还可以记录搜集错题，像百词斩那样，但要有科普，错题之后有科普能帮助学习。」

## 2. 原理

复习类工具的关键不是"题多"，是**答错之后能真正学会**。所以本项目定四条：

1. **可追溯**：每题带 evidence，答错显示原文片段 + 来源文件名。没有原文的题不出。
2. **不编造**：构建时强制校验 evidence 前 12 字必须在源文件中命中，否则拒绝出题。
3. **确定性**：题目顺序用日期偏移的固定步长算（不用随机），同一天打开题目一致。
4. **错题即教学**（v2）：答错自动弹出科普卡，一张卡只讲一个 idea ——
   生活画面 → 一个问题 → 一句话结论 → 原文锚点 → 可点开的外部来源。
   这是从 3Blue1Brown 风格 SPEC 借来的降认知负荷规则：一次只引入一个新对象、先图像后命名、
   每章只回答一个问题、结尾只收束一个点。**超预算就重写，不堆术语**。

**间隔重复（艾宾浩斯）**：答对后按 `1 → 2 → 4 → 7 → 15 → 30` 天推进阶梯；
答错退回第 0 阶、次日重来。"今日复习"模式只列出到期题。

**技术选择**：单文件 HTML 而非微信小程序。理由：无需开发者工具编译、可直接双击打开、
方便你把题目文本拿去校对、离线可用、改动只是重新生成一个文件。

## 5. 证据

- 题库构建输出：`BUILT 11 verified questions`，TOPICS = 早期 5 / 工业革命 4 / 工艺美术 2。
- 首轮我曾手写 29 题，原文核对后**只有 11 题可追**，另外 18 题（包豪斯、现代主义、
  后现代、绿色设计等）是我凭通用知识写的、DOC 里没有 → **全部删除**。
  这是本项目最重要的一条记录：**宁可少，不可编**。
- 科普卡 11 张一一对应；其中 9 张带可点开的外部来源（百度百科），2 张如实标注"外部来源未核实"。
- v2 静态验证：DOM 引用 31 个全部存在、占位符残留 0、`node --check` JS 语法通过。
- 外部科普来源集中在 4 个百度百科条目（设计 / 工艺美术运动 / 威廉·莫里斯 / 家居设计史），
  通过 WebSearch 取得，卡片里给的是原文链接，可点开核对。
