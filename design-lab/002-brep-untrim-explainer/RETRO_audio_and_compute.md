## 2. 之前怎么做（一页速查）

### 2.1 构造序列（原理 → 数据流）

```
storyboard.py  ← 唯一数据源：8 BEATS + PALETTE + CONFIG + AUDIO
      │
      ├── render.py     frame(t) 纯函数 → frames/00000.png … 01069.png
      │                     └── encode.py → brep_untrim.mp4（无声）
      │                                   └→ brep_untrim_with_audio.mp4（带音轨）
      ├── audio.py      sample(t) 纯函数 → soundtrack.wav（17 事件全由 BEATS 派生）
      │
      └── build_html.py → preview.html（Canvas 重画画面 + Web Audio 复现同一张事件表）
```

**核心原理**：不写画面、不写音频文件，写的是 `frame(t)` / `sample(t)` 两个纯函数。
时间 `t` 是唯一自变量，时间轴的唯一来源是 `storyboard.BEATS`。
于是「改一镜 `dur`」→ 画面、WAV、MP4、浏览器预览一起变，不会漂移。

**四条纪律**（已经做对，不要动）：
1. 单一数据源贯穿四端（渲染器 / 音轨 / 编码器 / 预览页）。
2. 三条禁令：不读系统时间、不用无种子随机、渲染时不联网 → 可 diff、可并行、可断点续渲。
3. 转场在 `frame(t)` 里算、包络在 `sample(t)` 里算，**不押在 ffmpeg 滤镜上**（本机精简构建没有 fade/overlay）。
4. 确定性可验证：连续两次 `audio.py` 的 WAV sha256 一致（`32d811a6…`）；`KIND` 从 tuple 重构成 dict 后哈希不变。

### 2.2 画面侧（用户已认可，冻结）

| 项 | 值 |
|---|---|
| 画幅 / 帧率 | 1600×900 / 24 fps / 1070 帧 / 44.6 s |
| 单帧成本 | ≈ 0.18 s，全片 ≈ 3.2 min |
| 风格 | 深色 Manim + Tech-Glow；青=原生底层曲面、橙=特征，其余全灰阶 |
| 几何 | 等轴测 2.5D 投影，无 3D 库；孔=参数化圆投影椭圆，圆角=4 条顶边弧带 |
| 成片 | 无声 2.05 MB / 带音轨 2.90 MB，H.264 yuv420p |
| 预览 | 单文件 HTML，画面 5 控件 + 声音 4 控件 |

画面侧已内化的坑：Consolas 无中文字形（自动切雅黑）、静态网格层只建一次、
glow 半分辨率模糊、PNG `compress_level=1`、contact sheet 八镜拼图自检、标签避让纪律。

### 2.3 声音侧（`audio.py` 现状，诊断对象）

| 层 | 实现 | 关键参数 |
|---|---|---|
| 氛围 pad（连续） | 4 个正弦叠加 + 呼吸 LFO | `pad_root=55 Hz`；`1.0 / 1.5 / 2.0 / 1.003` 倍频；`breath=0.62+0.38·sin(2π·0.11t)`；`pad_level=0.16` |
| 调性移动 | 每镜换根音并滑过去 | `pad_steps=[0,3,5,7,10,12,7,0]` 半音；`pad_glide=0.90 s` |
| 转场 cue | 每镜开头一声「叮」 | `scale=[220, 261.63, 293.66, 329.63, 392, 440, 523.25, 587.33]`；`atk=0.006 / dec=0.34` |
| 事件层 | 8 cue + 6 tick + thud/lift/chord 各 1 = **17 事件** | 包络 `(1−e^(−t/atk))·e^(−t/dec)`；谐波表里 `tick` 含 `5.4` 非整数倍频 |
| 输出 | 48 kHz / 16-bit / **mono** | `master=0.82`；`peak 0.5241 → gain 1.439 → ≈0.75`；`rms=0.1403` |

## 3. 算力账：这轮到底花在哪

| 阶段 | 单次成本 | 触发次数 | 说明 |
|---|---|---|---|
| 全片渲染 | 1070 × 0.18 s ≈ **3.2 min** | 多次 | 每改一处构图就重来一遍 |
| 八镜 contact sheet | 8 帧 ≈ **1.5 s** | 少数 | 其实已经是最便宜的自检，但没被当成硬门槛 |
| 音轨合成 | 2,140,800 采样 ≈ **2.8 s** | 少数 | 几乎免费 |
| 编码 + 整片解码校验 | 秒级 × 2（无声 + 带音轨） | 2 | 可合并 |
| 环境探测 | 4 轮试错 | 缺 numpy/imageio/cv2、两台 ffmpeg 能力不同、Git Bash `/c/` 路径、Consolas 中文字形 | 「用到才发现」，没有一次性 preflight |
| 构图返工 | 6 轮 | 片头标题重复、文字压几何、豆腐块、底层曲面糊成一片、孔消失太快、fillet 标签压橙带 | 每轮都要重出图才看得见 |
| 结构性返工 | 1 轮 | `KIND` tuple → dict（JSON 注入后 `K.dur` undefined） | 双端实现带来的额外成本 |

**最贵的一项不在这张表里**：音频链**没有任何可计算的听感指标**，
只验了哈希 / peak / rms / AAC 流存在 / JS 语法。
所以「好不好听」只能等真人听完再反馈 → 一次完整交付之后才闭环。
这就是本次「声音怪」被拖到最后才发现的根因，也是 §4 第 4 条要解决的。

> 结论：**省算力的重点不是让渲染更快，而是把「人肉验收」前移到代码自检，并减少全片重渲的次数。**

## 5. 声音为什么「怪怪的、不舒服」：7 条可追溯根因

| # | 症状 | 代码位置 | 机制 |
|---|---|---|---|
| 1 | **这是音效（SFX），不是配乐（score）** | `audio.py:60-84` | 17 个事件全是「叮/嗒/咚」提示音，没有和弦进行、没有旋律、没有情绪弧。用户说「主要是配乐」——判断准确。 |
| 2 | **没有「张力 → 解决」，所以没有恍然大悟** | `storyboard.py:180,185` | `pad_steps` 每镜换根音、`scale` 按镜头编号**单调上行**（A3→D5），是一路往前走，不是先悬后落。片尾 `chord` 只是一次性和弦，前面没有任何铺垫；且此时 pad 回到 55 Hz(A1)，与 D5 大三和弦不是主—属解决关系。 |
| 3 | **55 Hz 正弦持续 44.6 s = 低频嗡鸣** | `audio.py:105-128` | 纯正弦叠加没有自然泛音列，听感像电流/空调声；在小音箱上会掩蔽中高频并让耳朵疲劳。公开配方里 pad 音量仅 **0.06** 且带 2.5 s 淡入淡出；我们是 `0.16` 且从头到尾。 |
| 4 | **两个慢 LFO + 每镜滑半音 = 音高一直在飘** | `audio.py:105-118` | 0.3% 失谐拍频（≈0.165 Hz）+ 0.11 Hz 呼吸 LFO（±38%）+ 每镜 0.9 s 滑音，三者都是几秒周期的缓慢摆动。缺一个稳定的调性中心，正是「晕 / 不舒服」的来源。 |
| 5 | **pad 与 cue 不同源，后两镜不协和（最可计算的一条）** | `storyboard.py:180,185` | pad 从 A1 按半音走 `[0,3,5,7,10,12,7,0]`，cue 从 A3 走五声 `[220…587.33]`。前 6 镜恰好 4:1 协和；**beat 6**：pad=E2 82.4 Hz vs cue=C5 523.25 Hz ≈ **6.35×**；**beat 7**：pad=A1 55 Hz vs cue=D5 587.33 Hz ≈ **10.68×** —— 都不是简单整数比，且 pad 自带 1.5×/2× 谐波，会听出明显的「打架」。 |
| 6 | **2 ms 起音 = 机器味；5.4 倍频 = 金属刺耳** | `audio.py:41-48,146` | `atk` 最短 0.002 s，接近 click。公开配方明确记录「采样起音从 1 ms 拉到 **0.28 s**，机器味基本就是这么来的」。`tick` 谐波 `[4.0, 5.4]` 中 5.4 非整数 → inharmonic，且基频 `f*2` 再乘 4 已到 1.7 kHz 以上，碎、尖。事件 `dec` 最长 1.05 s，**没有尾音/混响**，声音发干。 |
| 7 | **mono + 无混响 + 无留白** | `audio.py:197` / `events()` | 单声道全挤在中间，声音扁、贴脸；pad 连续不断，没有 silence 做对比，导致「每一声提示音」都不再有分量。公开配方用 83/191/370 ms 三次交叉声道回声 + stereo；科普片声音设计指南把 **Silence** 单独列为设计要素。 |

**一句话诊断**：我们用「UI 音效生成器」的架构去承担「配乐」的任务 ——
等间隔提示音 + 一直变调的低频嗡鸣，恰好是「恍然大悟感」的反面
（后者需要稳定调性、渐进张力、关键点的解决、以及留白）。

## 6. Claude 系「恍然大悟感」到底是什么（原理对照）

### 6.1 公开配方的关键数字

检索到一份公开的 **3Blue1Brown 风格 explainer 视频 SPEC.md**（Claude 生成，非 Anthropic 官方规范；
3B1B 真实配乐作者为 Vincent Rubinetti）。它把配乐写成了可执行的谱子，与我们形成精确对照：

| 维度 | 该配方 | 我们 002 |
|---|---|---|
| 调性 | **D major 固定**，`Dmaj9 – Bm9 – Gmaj7♯11 – Asus2`，每和弦 8 s 循环 | 每镜换根音，8 镜 8 次变调 |
| 钢琴 | 加法合成，谐波 1–4 幅度 `1 / 0.42 / 0.18 / 0.08`，**高次谐波衰减更快**，包络 `exp(−1.6t)`，音符 **3.2 s** | 纯谐波等比叠加，音符 `dec 0.34 s`，无泛音演变 |
| 琶音 | 60 BPM 八分音符，上下行，**12% 音符跳过（固定种子）让它呼吸** | 每镜固定一声 cue，无留白 |
| Pad | 和弦最低 3 音降八度，每音 3 个正弦 detune `−0.12 / 0 / +0.12 Hz`，**2.5 s 淡入淡出**，0.07 Hz LFO ±20%，音量 **0.06** | 55 Hz 单根音 + 0.3% 比例失谐，0.11 Hz ±38%，音量 0.16 |
| 空间 | **三次交叉声道回声 83 / 191 / 370 ms**（0.28 / 0.20 / 0.13）+ **stereo** | mono，无混响 |
| 起音 | 钢琴 2–3 ms 但配长音符；采样音色**从 1 ms 拉到 0.28 s** 去机器味 | 2–30 ms，最短 2 ms |
| 整体 | 3 s 淡入 / 5 s 淡出，peak 0.8，48 kHz stereo；配乐在旁白处 sidechain duck | 0.7 / 1.4 s 淡入淡出，peak ≈0.75，mono |

另两份科普片配乐指南的结论一致：
- **情绪弧线**：Problem（张力）→ Solution（清晰 / 释然）→ Resolution（**resolved final chord / sense of arrival**），
  「音乐要有起承转合，不是从头铺到尾的墙纸」。
- **音效克制**：「Every element doesn't need a sound」「Constant whooshes quickly become tiring」。
- **Silence 是设计要素**：刻意的静默制造强调与对比。

### 6.2 「恍然大悟」的听觉机制

不是「好听」，是**一个可预期的张力被解决**：

```
能量 / 张力
   ▲                        ╭─╮  ← 揭示点：一个明亮、稳定、解决到主和弦的音
   │                    ╭───╯  ╰──╮
   │              ╭────╯           ╰────╮  ← 回落 / 余韵（长 release + 混响尾）
   │        ╭─────╯                      ╰──
   │  ╭─────╯   ← 缓慢积累（稳定调性上的渐强 / sus 和弦）
   └──┴──────┴──────┴──────┴──────┴──────┴──→ 时间
     提出     铺垫    反直觉   揭示     收束
     (0–12s) (12–30s) (30–40s) (40–44.6s)
```

三个必要条件：① **稳定调性**做地基（否则耳朵不知道「解决」到哪里）；
② **渐强/悬念**积累能量；③ **在概念揭示的那一帧**落到明确主和弦，并给长尾音。
外加④ 之前要有留白，那一声才有分量。

我们当前是「每 2.6 秒一声等间隔提示音 + 音高一路往上飘」，
既没有地基，也没有积累，更没有落点 —— 所以听感是「碎、飘、怪」，而不是「啊，原来如此」。

## 7. 明天讨论的议程（待决，不预设结论）

| # | 待决问题 | 建议起点（供讨论，不是结论） |
|---|---|---|
| 1 | 三条禁令是否对**素材**开口子：允许「联网一次生成/取音色 → 固化入库 → 之后渲染仍不联网」？ | 若能接受，音色质量可一步到位；若不接受，继续纯正弦加法合成也能改善（1/0.42/0.18/0.08 + 高次快衰减） |
| 2 | 是否改 **stereo + 简单混响**（三次延迟即可，不必外部卷积）？ | 这是「空间感 / 不贴脸」性价比最高的一步 |
| 3 | 和弦进行怎么选？固定调性 8 s/和弦循环，还是按情绪弧线走 I–V–vi–IV？ | 必须**与分镜编号解耦**，否则改字幕就牵动配乐 |
| 4 | 事件密度从 17 降到多少、 cue 是否只留在「揭示点」？ | 建议 ≤8，且 pad / cue 统一到同一个调（修掉 §5 第 5 条） |
| 5 | 情绪弧线怎么对齐这 8 镜？ | 提出 0–12s / 张力 12–30s / **啊哈 30–40s（对应 independence 镜）** / 收束 40–44.6s |
| 6 | 低频怎么处理？ | 55 Hz 持续嗡鸣 → 降音量 + 加高通/淡入淡出，或改成和弦根音的短音 |

**建议保留 3–6 个滑块**（用户长期偏好，别给「只能看不能动」的结果）：
`配乐强度` / `张力→解决幅度` / `空间感(混响)` / `起音柔和度` / `提示音密度` / `低频量`。

**验收方式也要一起定**：明天改完先跑 `audio.py --info` 看 §4 的 6 个指标，
再出 10 s 试听片段，最后才全片渲染 —— 不再「一次交付等耳朵」。
