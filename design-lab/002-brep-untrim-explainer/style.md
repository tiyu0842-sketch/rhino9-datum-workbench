# style.md —— 002 号片的项目级风格规格

> 这份文件的作用：让「下一支片子」不必重新讨论审美。
> 帧率、配色、字体、禁用风格写死在这里，render.py 的 CONFIG / PALETTE 是它的可执行版本。
> 对应 Claude 系代码视频的那条经验：把风格写进项目说明，而不是每次提示词里重复。

## 1. 画幅与节奏

| 项 | 值 | 理由 |
|---|---|---|
| 分辨率 | 1600 × 900（16:9） | 1080p 的 5/6 体积，文字仍锐利，渲染快一半 |
| 帧率 | 24 fps | 科普片足够；30/60 只会让逐帧成本线性上涨 |
| 时长 | 44.6 s / 1070 帧 | 一个概念一镜，8 镜，每镜 3.2–7.2 s |
| 单镜上限 | 7.2 s | 超过就该拆镜；观众注意力在这类片子里约 8 s 一换 |
| 转场 | 0.38 s 叠化 | 不用 ffmpeg 滤镜，在帧内做（编码器是精简构建，没有 fade） |
| 缓动 | easeInOutCubic 为主，标题用 easeOutBack | 线性动画是「廉价感」的最大来源 |

## 2. 配色 token

| token | 值 | 用途 |
|---|---|---|
| ground | `#12141A` | 背景 |
| grid | `#24262C` | 64px 细网格，alpha 0.35 |
| text | `#ECEDEF` | 主文字 |
| muted | `#9A9EA8` | 说明行、副标题、单位 |
| line | `#8E929C` | 中性描边（盒体棱线） |
| surface | `#5CC8E8` 青 | 底层曲面 / 原生面 |
| feature | `#FF8A28` 橙 | 特征 / trim 环 / 圆角 —— 与 Rhino 插件视口的高亮同色 |
| accent | `#FFD25A` 黄 | 选中、进度点、强调数字 |
| good | `#8BD17C` 绿 | 结论、保留 |
| bad | `#FF6B5E` 红 | 否定、`null`、报错 |

**双色语义固定不变**：青 = 原生/底层，橙 = 特征/后加。
整支片子只有这两个语义色在承担信息，其余都是灰阶。这是「一眼可读」的根。

## 4. 版式网格

```
y=18–44     顶栏：左侧栏目名 / 右侧 03 / 08 12.5s + 分段进度条
y=110–254   右栏：滚动数字（数字在上、单位在下，右对齐 x=1510）
y=132–230   左栏：说明行（圆点 + 26px 文字，最多 3 条）
y=250–650   中部：3D 主体（等轴测，中心 x=0.63W / y=0.46H，缩放 5.2）
y=732–870   底部：镜头标题 + 副标题（左侧 10px 黄色竖条做节拍标记）
```

**避让纪律**：标签与几何重叠一次就必须换位。fillet 镜的红叉从「顶面右上」挪到
`x=1330` 的右侧空白带，就是实测压住橙带后改的；independence 镜两个标签从
`q[0]-190` 挪到 `q[0]-250`，同理。

## 5. 禁用风格（明确不做的事）

- 不做全屏渐变光污染：光斑只两粒、alpha ≤ 0.17，且半分辨率模糊。
- 不做快速闪白 / 抖动 / glitch：这是几何原理片，抖动只会干扰读数。
- 不堆 emoji 和「AI 味」图标：所有语义靠颜色 + 编号 + 文字。
- 不做匀速位移：一切运动必须过缓动函数。
- 结构线**不设 0**：密度下限 2，只降密度不隐藏（用户对 Alias 显示模式的明确反馈）。
- 不出现无法解释的数字：所有上屏数字都能追到 E-024/E-025 的实测记录。

## 6. 三条禁令（确定性渲染）

1. 不读系统时间（没有 `time.time()` / `Date.now()` 参与画面）
2. 不用无种子随机（光斑位置由 `seed` 常量经 sin/cos 公式生成）
3. 渲染时不联网

守住这三条，同一份代码每次渲染的每一帧逐像素相同 —— 才能 diff、才能并行、才能复现。

## 7. 性能做法

| 做法 | 收益 |
|---|---|
| 静态层（网格 + 暗角）只构建一次，每帧 `copy()` | 省掉 1070 次网格绘制 |
| glow 在 1/2 分辨率上 `GaussianBlur` 再放大 | 耗时约 1/4，光晕更柔 |
| 帧用 PNG `compress_level=1` | 文字锐利，写入快 |
| 转场用两次纯函数渲染叠化 | 可乱序/并行渲染，不依赖上一帧状态 |

实测：1600×900 单帧约 0.18 s，1070 帧约 3 分钟出完，MP4 约 2–3 MB。

## 8. 音频规格（v3 · 已落地，与画面同一套确定性纪律）

> **状态（2026-11-24 晚）**：v2 的「声音怪、不舒服」已完成诊断 → 决策 → 实现 → 出片。
> 本节写的是**当前成片的真实规格**；v2 的旧规格只作为「为什么改」的历史留在
> `RETRO_audio_and_compute.md` §5，不要照着旧参数复用。

**声音仍是 `sample(t)` 纯函数**：`t = i / sample_rate`，但时间轴来源从 `BEATS`
换成了 `storyboard.AUDIO` 的**绝对秒**。这是 v3 最关键的一步：配乐与分镜编号解耦，
改一句字幕 / 改一镜 `dur`，配乐一动不动（省算力清单第 9 条）。
`audio.py` 的 `events()` 直接读 `AUDIO["events"]`，`build_html.py` 把同一张表注入预览页。

| 项 | v3 当前值 | v2 旧值 |
|---|---|---|
| 采样规格 | **48 kHz / 16-bit / stereo（2 ch）** | mono |
| 时长 | 44.60 s / 2,140,800 采样 / 每声道 | 同 |
| 调性 | **固定 D major**，`Dmaj9 – Bm9 – Gmaj7♯11 – Asus2`，8 s/和弦、32 s 一轮 | 8 镜换 8 次根音 |
| 事件数 | **7**（最小间隔 3.54 s） | 17 |
| 情绪弧 | 提出 0–8.6 / 积累 8.6–28.4 / **啊哈 28.4–35.4（t=32.0 主和弦落点）** / 收束 35.4–44.6 | 单调上行，无落点 |
| pad | 和弦最低 3 音 × 固定 ±0.12 Hz detune × 80 Hz 高通 × 0.07 Hz ±20% 呼吸，**level 0.06** | 55 Hz 持续嗡鸣 / level 0.16 |
| 空间 | 左右不同三抽头房间回声 `L 83/191/370 ms`、`R 97/211/389 ms` | 无 |
| 起音 | `atk` 20 / 25 / 30 ms，谐波全为整数倍 | 最短 2 ms + 5.4 非整数倍频 |
| 淡入淡出 | 2.5 s / 3.5 s | 0.7 / 1.4 s |

**三层结构（v3）**

1. **和弦底座 pad**（连续）：按绝对秒取当前和弦的最低 3 个音，每音 3 个固定 detune 正弦，
   逐音过一阶高通幅度响应 `f/√(f²+80²)`，再乘呼吸 LFO、四段能量包络与 `pad_level=0.06`。
   不再有 55 Hz 单根音、不再按镜头滑半音。
2. **琶音**（中段）：60 BPM 八分音符（0.5 s），只在「积累」段进入，给张力爬升。
3. **离散事件**（7 个）：`cue ×5 / thud ×1 / chord ×1`，频率一律由 MIDI 换算，
   与当前和弦同调（修掉 v2 第 6/7 镜 pad↔cue 6.35× / 10.68× 的不协和）。
   `t=32.0` 的 `chord` 是「啊哈」落点：Dmaj9 主和弦回归、`dur 4.5 s / dec 1.6 s` 长尾。

**四条硬规矩（保留并加强）**

- 每个事件包络 `(1−e^(−t/atk))·e^(−t/dec)` **从 0 起、回 0 收**；波形跳变 = 爆音。
- 全局 `fade_in 2.5 s` / `fade_out 3.5 s`；段间用 0.8 s smoothstep 过渡能量，不硬切。
- 叠加后统一归一化 + 限幅；`audio.py --info` 直接打印可计算的听感指标，不再等真人听完。
- 不加载任何外部音频素材；包络、高通、房间回声全在 Python 采样点里算完，**不依赖 ffmpeg 滤镜**。

**离线听感自检（实测输出，`python audio.py --info`）**

```
events 7 | density 0.157/s | min_gap 3.54 s
atk_ms [20.0, 25.0, 30.0] | chord_tone_hits 6/7
key_changes 5 | chord_loop 32.0 s | 80 Hz 高通（原 55 Hz 嗡鸣已移除）
```

对比 v2 的 17 事件 / 0.38 事件每秒 / 最小间隔 0.16 s / 起音 2 ms：
「碎、尖、飘」的三条可计算根因都消失。

**确定性验证**：`audio.py` 两次输出 WAV 逐字节一致；当前
`soundtrack.wav` sha256 `1adfa21b…`，`preview_10s.wav` `8275b772…`，
`brep_untrim_with_audio.mp4` `204ab6e8…`。
`ffprobe` 实测：H.264 1600×900 24 fps + **AAC 48 kHz 双声道**，44.583333 s / 3,077,540 B。

**编码器分工（实测，别凭路径猜）**：本机两个 ffmpeg 能力不同。
`KeyShot Studio\bin\ffmpeg.exe` 是 `--disable-everything` 精简构建，
**0 个音频编码器、0 个音频滤镜、连 wav demuxer 都没有**；
`KS2024\bin\ffmpeg.exe` 是完整构建，有 `aac / libmp3lame / pcm_s16le` 与 `amix / afade`。
所以 `find_ffmpeg(need_audio=True)` 会实测 `-encoders` 再挑，无声版仍用精简版，
带音轨版自动跳到完整版。这条是探测不彻底修正过来的：第一版只找到精简构建，
就误以为「本机没法加音轨」。

**禁用**：不用无种子噪声、不做突然静音、不用滤镜叠化转场、不把人声假装成代码生成、
不引入外部音色素材。人声旁白是可选外部插槽，见 `narration.md`。
