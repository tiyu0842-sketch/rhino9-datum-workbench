# narration.md —— 逐镜旁白稿与时间码

> 这份文件是**人声旁白的插槽说明**，不是自动合成的产物。
> 当前成片的音轨是 `audio.py` 用代码算出来的程序化音效 + 氛围层（见 `style.md` §8）。
> 你只要给一个 wav，编码时会自动混进去，不用改任何代码。

## 怎么混入

1. 按下面的时间码录一段中文旁白，保存为 `narration.wav` 放到本目录（48 kHz / 单声道最佳，其它格式 ffmpeg 会自动重采样）。
2. 跑：

   ```bash
   python encode.py --audio
   # 或显式指定路径
   python encode.py --audio --narration D:/voice/take01.wav
   ```

3. `encode.py` 检测到 `narration.wav` 后走 `amix`：程序化音轨 100% / 旁白 85%，
   以音轨的 **44.60 s** 为准，输出 `brep_untrim_with_audio.mp4`。
   不想要程序化音轨时，把 `AUDIO.cue_level` 与 `AUDIO.pad_level` 调到 0 再跑 `audio.py` 即可。

## 时间码与文案

时间码不是手写的，来自 `storyboard.cumulative_starts()`；改一镜 `dur`，这张表自动跟着变。

| # | scene | 区间 (s) | 旁白文案 |
|---|---|---|---|
| 0 | title | 0.00 – 3.20 | 同一个立方体，两种「多出来的形状」。 |
| 1 | two_layers | 3.20 – 8.60 | B-rep 有两层：底层曲面是一整张没被破坏的平面，裁剪环只是画在它上面的边界。钻孔只动了第二层。 |
| 2 | hole_untrim | 8.60 – 14.60 | 孔，就是多了一个内环。底层曲面一点没坏，所以取消它，只要把那个环删掉。面数从八变成七。 |
| 3 | selective_holes | 14.60 – 21.20 | 两个孔，只勾一个。H1 的两个内环被删，H2 纹丝不动。所谓「必须先去圆角」，其实是个伪约束。 |
| 4 | fillet | 21.20 – 28.40 | 圆角不一样。它是滚球扫出的一整圈新曲面，没有更大的底层曲面可以还原，UntrimOuterLoop 恒为 null。 |
| 5 | independence | 28.40 – 35.40 | 所以，圆角盒加一个孔，只删那个孔的内环，得到的还是纯圆角盒。两个模块完全独立，任意顺序。 |
| 6 | conclusion | 35.40 – 40.60 | 孔是可抹掉的边界，圆角是必须重新缝合的实体。机器给候选，人来裁决，明确报出，不偷偷改。 |
| 7 | outro | 40.60 – 44.60 | 每一帧都由代码算出。改一句字幕，只是一次 diff 加一次重渲染，不是重新抽卡。 |

语速参考：中文科普旁白约 4–5 字/秒。上表长句略密，录制时可按镜长删减，
但**不要改时间码**——数字上屏与音效事件都锚在 BEATS 上，改时长要回 `storyboard.py` 改 `dur`。

## 为什么没有自动生成人声（如实说明，不吹牛）

1. **离线 TTS 这条路被环境挡了**：Windows 自带 SAPI 需要 PowerShell `Add-Type` 加载
   `System.Speech` 程序集，当前会话的沙箱安全策略明确拦截
   （`Add-Type compiles and loads .NET code at runtime`）。按纪律没有换等价路径绕过。
   而且系统是否装有中文语音包也无法确认——即使能调用，`Zira/David` 也读不了中文。
2. **联网 TTS 违背项目自身的三条禁令**（不读时钟 / 不用随机 / 不联网），
   且当前代理会让外部请求 502。它还会引入一个不可复现的外部资产，
   跟「同一份代码每次出同一条片」直接冲突。
3. 因此把人声做成**可选插槽**：文案与时间码在这里给全，音频文件由你提供，
   编码链已经写好 `amix` 混流。这样既不假装能做到，又留了完整的下一步。

如果你希望换成「联网 TTS 生成后固化为仓库内 wav，之后所有渲染都不再联网」，
那是另一条可接受的路径：外部素材只生成一次、入库、之后确定性不变。说一声我就接。
