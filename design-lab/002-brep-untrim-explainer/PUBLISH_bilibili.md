## 3. 简介（整段复制）

```
同一个立方体，上面有一个孔、四边有圆角。
为什么孔能一键消失，圆角却不能？

这不是操作技巧，是 B-rep 的拓扑事实：
· 孔 = 底层曲面上的一个「裁剪环」，删掉环，面自己合上；
· 圆角 = 滚球扫出的一整圈新曲面，没有更大的底层曲面可还原，
  UntrimOuterLoop 恒为 null，只能删整圈过渡面再重新缝合。
所以「去布尔必须先去圆角」是个伪约束：两个模块本来就可以独立、任意顺序。

全片 44 秒，画面与音轨都由代码逐帧、逐采样算出：
不加载任何图片/音乐素材，不联网、不读系统时钟、不用随机数。
同一份代码，每次出来的是同一条片。

素材与源码：https://github.com/tiyu0842-sketch/design-lab
（若仓库尚未公开，这条先删掉，别放空链接）

章节：
00:00 两种「多出来的形状」
00:03 两层结构：底层曲面 + 裁剪环
00:08 孔 = 多一个内环，删掉就合上（8→7 面）
00:14 两个孔只删一个，另一个纹丝不动
00:21 圆角 = 新增的一整圈过渡曲面
00:28 圆角盒 + 1 孔：只删孔的内环，还是纯圆角盒
00:35 结论：边界可抹，实体须缝
00:40 每一帧都由代码算出

本片是「代码生成视频」的实验记录，不是 AI 文生视频：
没有抽卡，没有随机，改一句字幕就是一次 diff 加一次重渲染。
```

## 4. 置顶评论（发布后自己发，然后置顶）

```
补三条片子里没展开的：

1) 「孔能删」的前提是它只动了底层曲面的裁剪环。如果孔是和别的特征一起被布尔合并过，
   底层曲面可能已经不是一张完整的平面，这时删环会连带别的面——所以工具要先判断再删。

2) 片子里的 8→7、11→10 面数、235922.14→239315.06 体积，都是 Rhino 9 实测读数，
   不是示意数字；完整记录在仓库的 experiment-log（E-024 / E-025）。

3) 画面和声音都是代码算的：Python + Pillow 逐帧，音轨是正弦叠加 + 指数包络，
   44.58 秒 / 1600×900 / 24fps。想看哪一段怎么做，评论区说，我拆开讲。
```

## 6. 文案口径（什么能说、什么不能说）

| 能说 | 不能说 |
|---|---|
| 「画面与音轨都由代码逐帧/逐采样算出」 | 「AI 一键生成视频」 |
| 「同一份代码每次出同一条片」 | 「完全无损/绝对精确」（圆角是示意面，不是真实滚球扫掠） |

| 「配乐是程序合成的，没有版权素材」 | 「配乐达到专业水准」（真人听感尚未验收） |
| 「伪约束被打破：两个模块可独立」 | 「FeatureWorks 没用 / SolidWorks 做不到」（没做过横向评测） |
