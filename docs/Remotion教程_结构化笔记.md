## 1. 一句话定位

这不是"AI 生成视频"的教程，是**让 Agent 写 React 代码、用 Remotion 逐帧渲染出片**的完整工作流——
重点在流程（需求聊清 → 攒模板 → 复用），不在某一句提示词。

## 2. 核心内容分块

### 块一：视频模型 vs Remotion（该选哪个）
| | 视频生成模型（可灵等） | Remotion（代码动画） |
|---|---|---|
| 自然质感（花朵生长、光影） | ✅ 强 | ❌ 生硬，靠参数模拟 |
| 精确咬合（音符落点、数据同步） | ❌ 做不到 | ✅ 主场 |
| 产出 | 成片 | 成片 + **可复用代码资产** |
| 计费 | 按时长/次数 | Token/额度，改稿也烧 |

金句："自然的画面交给视频模型，精确的咬合交给代码；前者买成片，后者攒资产。"

### 块二：模型梯队（分工比记名字重要）
- **第一档 审美标杆**（Opus 5.5）：给参考视频或风格就能抓感觉，一版定稿。
- **第二档 主力做模板**（Astra）：不需事无巨细指挥，但审美/导演能力有差距。
- **第三档 批量复用**（DeepSeek-v4-flash）：从零做"跟被雷劈了一样"；但拿第二档做好的运动模板去复刻同类，就稳。
- **Harness 陷阱**：同一项目同样提示词，WorkBuddy 里跑 Remotion 有时一两小时/几百积分还失败，切 Claude Code 反而顺——环境对 Remotion 的友好度决定成败。

### 块三：开工三件事
1. **装官方 Skill**：`npx skills add remotion-dev/skills`，核心是 `remotion-best-practices`，另有 create/studio/render。
2. **建长期动效库**：根目录统一管依赖，`effects/` 下每个动画一个子目录，别每片新建项目（初始化就烧掉一截额度）。
3. **补生图能力**：Codex 内置 ImageGen；Claude 无内置，配 codex-image skill 代劳。
   Remotion Studio（`localhost:3000`）能实时预览、拖动调参——"先开 Studio 再写代码"。

### 块四：案例——音符跳跃（从零做模板）
- 素材：巴赫 C 大调前奏曲 BWV 846（公有领域、音符密集），音频 + MIDI + MusicXML。
- 流程：给参考视频 → 问"能实现吗/要备什么素材" → 让 AI 写专业提示词 → Astra 中强度跑约 18 分钟出第一版 → 只调亮度/跳跃幅度几版。
- 规律：**从零做模板很难一次定稿；模板做好后同类复用大多一次定稿**。

### 块五：改稿为什么总改不动
- 开放型创作（只给风格："剪纸风 Vlog"）→ 40 秒第一版就过。
- 精细控制（地图转场：大小/倾角/透明度/推进时机全指定）→ 几秒的片来回磨多轮。
- **锁放原则**：锁死风格与主题；放开画面元素、镜头角度、动画细节。
- 调参用 Studio 把位置抽成可编辑参数，动手前先 Git 存版本（Studio 改动会写回代码）。

### 块六：素材与特殊场景
- 提前出关键静态图再讨论，比空聊需求准。
- 手绘风：简单线稿走 SVG 路径显现；复杂线稿走"遮罩逐步显现"。
- 无参考时：语音唠嗑式描述 + 截图，或直接把旁白文本给 AI。
- 地图：高德开放平台申请 Web 服务 Key，配 `.env` 不要贴进对话。
- 透明底素材开头就说，避免 PPT 播放出黑边锯齿。

## 3. 方法 / 原理（可复现）

**核心机制**：视频 = 一个函数，`frame → 画面`。Remotion 用 `useCurrentFrame()` + `interpolate()`，我们用 `frame(t)` 纯函数。这是同一件事的两种语言。

**三条可迁移的纪律**：
1. 能测量的不要猜——BPM、节拍点、人声频段占比都用脚本测，AI 只负责设计。
2. 一定要看渲染结果——关键帧拼图是最便宜的质检，"代码能编译不代表画面好看"。
3. 保留每个版本——多 Composition / 多目录，新尝试不覆盖旧版本。

**卡点做法（来自交叉验证的实战文）**：
```typescript
export const BPM = 128;
export const beatFrame = (beat: number) => Math.round(beat * (60/BPM) * FPS);
```
事件用拍号定位，不用"第 137 帧"；每次底鼓给画面缩放脉冲，让片子"跟着音乐呼吸"。

## 4. 可借鉴点（对照我们自己的 code-video-deterministic skill）

| 借鉴项 | 我们的现状 | 优先级 |
|---|---|---|
| 拍点驱动时间轴 + 底鼓呼吸脉冲 | 有绝对秒情绪弧，但画面没真正咬拍 | **P0** |
| 抽 `primitives.py` 动效库 | 每片复制 render.py 重写 scene | **P0** |
| 避开"AI 味"禁令（粒子/紫渐变/随机3D） | 未明文禁止 | P1 |
| 锁死风格主题、放开画面细节 | SPEC 有画面清单但无锁放栏 | P1 |
| 逐词时间戳驱动画面 | 旁白按镜头起点固定对齐 | P1 |
| 长期动效库目录约定 | 每期独立目录已有，缺共享 primitives | P1 |

**我们的优势别丢**：完全离线、零外部素材、无版权风险、晓晓女声已验证。Remotion 方案依赖付费 API / CC0 素材下载 / Node 环境。
