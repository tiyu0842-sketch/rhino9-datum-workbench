## 0. 一句话定位

Mesh2Surface 做的事，本质就是**把"离散的三角网格"变成"可编辑的 NURBS 曲面"**——
像把照片矢量化成曲线一样，把扫描网格"矢量化"成曲面。
你的 NFF 插件解决的是这条路的前处理：**按法向把面筛出来，分好组，再交给逆向**。
两者串起来正好是一条完整链：`扫描网格 → 法向分组筛选 → 逆向拟合曲面 → 偏差校验`。

## 1. Mesh2Surface 的原理拆解（按功能）

### 1.1 Extract Shapes（提取基本体）— 最该先做
**原理**：在点云/网格上做**最小二乘拟合（best-fit）**，把局部点集拟合到解析曲面：
| 形状 | 拟合原理 | Rhino 内核可借力 |
|---|---|---|
| 平面 | 点集协方差最小特征向量 = 法向；质心 = 原点 | `Plane.FitPlaneToPoints()`（**需真机确认签名**） |
| 圆柱 | 点到轴线距离最小化；轴向由局部法向聚类决定 | 拟合圆 → `Cylinder` |
| 球 | 四点定球初值 + 距离方差最小 | `Sphere.FitSphereToPoints()`（**需确认**） |
| 旋转面 / 拉伸面 | 先拟合母线/截面曲线，再绕轴旋转或沿方向拉伸 | `Revolution` / `Extrusion`（**需确认**） |
**关键**：拟合是局部的——用户框选一片区域，算法在这片点上拟合，再用**偏差分析**判断好坏。

### 1.2 Segmentation（按曲率自动分割）— 与 NFF 最互补
**原理**：计算每个顶点的**曲率**（主曲率 k1/k2、高斯曲率 K、平均曲率 H），按阈值把网格切分成"曲率相近的片"：
- K>0 凸区（球帽）、K<0 鞍区、K≈0 平坦/圆柱区；
- 边界落在曲率突变处 = 特征边。
**这正是 NFF 的天然升级**：NFF 按"法向夹角"筛，Segmentation 按"曲率"筛。
两者结合 = 既有朝向分组，又有曲率分组 → AI 分面的前处理就完整了。

### 1.3 Deviation analyzer（偏差分析）— 质量闭环
**原理**：把拟合出的曲面对比原始网格，计算**点到曲面的最短距离**，用色阶图显示（绿=合格，红=超差）。
这是"能测量就不要猜"的典型：拟合好不好，不看感觉看数字。
**Rhino 现成能力**：`Surface.DistanceTo(point)` / `Mesh.ClosestPoint()`（**需真机确认**），
可自己算 RMS 偏差 + 色阶着色。

### 1.4 Cross sections / 2D Sketch（截面提取）
**原理**：用一簇平行平面与网格求交，得到截面曲线；用户据此画 2D 草图，再做拉伸/旋转。
**Rhino 现成能力**：`Rhino.Geometry.Intersect.Intersection.MeshPlane()`（**需确认**）。

### 1.5 3D Sketch / Snap-to-mesh（在网格上画线）
**原理**：鼠标射线与网格求交（`Mesh.Raycast`），把命中点投影贴合到网格表面 → 得到贴合曲线。
**Rhino 现成能力**：`Mesh.Raycast` / `Mesh.ClosestPoint`（**需确认**）。

### 1.6 曲面构建（CurveNetwork / Quad / Toleranced Patch）
- **CurveNetwork**：给一组首尾相接的曲线网络，插值出一张面（Coons patch 思想）。
- **Quad Surface**：有机形，四边网格驱动，`NurbsSurface.CreateFromCorners` / loft 类。
- **Toleranced Patch**：带偏差约束的自由曲面，边拟合边控误差。
这一层最难，**不建议第一版碰**——先把 1.1/1.2/1.3 做扎实。

## 2. 与 NFF 的衔接点（你的独特优势）

NFF 已真机验证通过的部分：
- 算法：叉乘求面法线 → `θ = acos(n·d)` → 角度区间筛选；支持参考面、双向模式、角度分箱 `Bins`。
- Python（GhPython + Rhino 命令）+ C#（.rhp + .gha）双实现，24 项测试 + 真机回归全过。
- HANDOFF 里"做了一半"= **步骤 3–7 的剥离加工链路只有技术方案，无真插件代码**。

**衔接设计**（这是复刻的核心思路）：

```
扫描/现有网格
    │
    ├─ [NFF 已有] 按法向筛选 + Bins 分箱 → 得到"朝向族"面集合
    │
    ├─ [新增] 按曲率分割/筛选 → 得到"曲率族"面集合
    │
    ├─ [新增] 两族求交 → 候选"可拟合面片"（如：朝上 + 平坦 = 顶面）
    │
    ├─ [新增] Extract Shapes：对每片做 best-fit → 解析曲面
    │
    └─ [新增] Deviation：拟合面 vs 原网格 → RMS + 色阶 → 合格才输出
```

**为什么这个组合比单纯复刻 Mesh2Surface 好**：
Mesh2Surface 是"人框选 → 拟合"，你是"法向+曲率自动分组 → 批量拟合 → 自动校验"。
前者是交互式工具，后者是**可批量、可脚本化**的前处理流水线——正好服务你说的"AI 分面"。

## 3. 复刻优先级（最小可跑版本）

| 阶段 | 功能 | 依赖 | 难度 | 交付 |
|---|---|---|---|---|
| **P0** | NFF 加曲率列 | 现有 NFF + `Mesh.FaceNormals` | 低 | 输出每个面的曲率（高斯/平均） |
| **P0** | 平面 best-fit | 点集 + 最小二乘（纯数学，自己写） | 低 | 框选面→拟合平面 |
| **P1** | 偏差分析 | `Mesh.ClosestPoint` / `Surface.DistanceTo` | 中 | RMS 数字 + 色阶着色 |
| **P1** | 圆柱/球拟合 | 最小二乘（自己写或用内核） | 中 | 常见基本体 |
| **P2** | 按曲率自动分割 | P0 曲率 + 连通分量 | 中高 | 自动分组 |
| **P3** | 曲线网络/自由曲面 | GH/RhinoCommon loft | 高 | 有机形逆向 |

**P0 就能跑出闭环**：法向筛出一组面 → 拟合平面 → 报偏差。先证明链路通，再加形状。

## 4. 实现路径选择（犀流工作流第 3 步：先定宿主再定手段）

- **宿主**：Rhino 9（你的环境，.NET 8）。
- **形态**：沿用 NFF 的双形态——GH 组件（Grasshopper 数据流）+ Rhino 命令（脚本化批量）。
- **语言**：C# 插件（进程内 Roslyn 编译，你已有工作台）；算法核心可先用 Python 验证数学。
- **不动的部分**：NFF 已验证的法向算法与接口（改算法要 Python/C# 同步）。
- **新增部分**：独立的 `SurfaceFit` 模块，通过面索引与 NFF 输出对接。

**数据结构约定**（避免双数据源）：
- NFF 输出：`KeptFaces`（面索引）+ `AngleGroups`（分箱）；
- 新增模块输入：面索引列表 → 取网格顶点 → 拟合；
- 输出：拟合曲面 + 偏差统计，写回文档字符串（随 .3dm 保存）。
