# 特征识别工具 / RhinoFeatureWorks v1.5.0 使用手册

## v1.5：模型上直接编号，点边就能选特征（推荐用法）

新版面板不再是“一排看不懂对应关系的 checkbox”：

1. `FWSelect` → 点实体 → 自动识别 → 自动弹面板（v1.4 的两段式不变）。
2. **看编号**：模型上每个特征组旁边写着 `F1/F2…`（圆角）或 `H1/H2…`（孔洞），
   面板行首是同一个编号 —— 一行对一个特征。
3. **点行定位**：在面板点某行 → 视口里该组变青色粗线，其余压暗；再点「缩放到选中项」可拉近。
4. **直接点模型选特征**：点「视口拾取边/面」→ 到模型上点那条圆角边或孔边 →
   对应行自动打勾、视口高亮。主体平面等非特征边会提示“不属于已识别特征”。
5. **决定去留**（语义是显式的，点之前看清）：
   - `取消选中 N 项` —— 只删勾中的特征；**一个都没勾时不会删任何东西**；
   - `保留全部（不改模型）` —— 什么都不改，只关掉聚焦显示；
   - `全部取消 → 回毛坯` —— 全部特征一起去掉。
6. 一次操作仍是一个 Undo，Ctrl+Z 可整段回退。

> 部分取消跨通道时，重缝毛坯可能“顺带”恢复其他特征，这是 B-rep 整面重缝的结构性限制，
> 命令行会如实报出连带组数；不是 UI bug。

## v1.4：敲命令 → 点物体 → 自动弹面板（两段式）

参考 XNurbs 的辅助面板做法，v1.4 把流程收敛成两段：

1. 敲 `FWSelect`
2. 点选一个实体——**点选本身就是"载入"**，不用先把对象加进面板
3. 插件自动识别，视口里特征面亮橙、其余面半透明锁定，**并自动弹出「特征取消」面板**
4. 面板左列圆角通道、右列孔洞通道，列出识别到的特征并集；勾选后点对应「取消」按钮即剥离特征、回毛坯
5. 面板没自动弹出时，手动敲 `FWCancelPanel` 即可

> v1.4 同时修复了面板注册失败（`type must have a GuidAttribute`）：面板类补齐了类级 `[Guid]` 特性。

Rhino 9 上的 SolidWorks FeatureWorks 风格特征识别插件。它把一个"没有历史、只有几何"的实体（比如别人发来的 STEP），反向拆成一棵特征树——圆角、孔、槽——然后让你对这棵树做抑制、改参数重建、还原毛坯。

## 0. v1.3 最快上手：选中 → 看证据 → 取消 → 再编辑

这是本版主流程，针对「倒完角 / 布尔完不满意，不想手工备份、不想重画」。

1. `FWSelect` → 点一个实体（多重曲面、单一曲面都行）
   - 除特征外的面变灰半透明（Rhino 里「锁定」的视觉语言），做过的特征面亮橙浮在里面
   - 命令行同时列出：圆角通道 N 组 / 孔洞通道 M 组
2. 两种取消方式任选：
   - 命令行：`FWCancel` → 选 `Hole` / `Fillet` / `All` → 输组号（0 = 该通道全部）
   - 面板：`FWCancelPanel` → 在圆角 / 孔洞两列里**勾选** → 点对应「取消」按钮
     （不勾选直接点 = 取消该通道全部；顶部「选实体并识别」可从面板直接起步）
3. 取消后插件会自动重新识别并重开聚焦，可以接着取消下一组
4. `Ctrl+Z` 一次退回操作前（整段操作在同一个 Undo 记录里）
5. 再运行 `FWSelect` 关闭聚焦，显示完全恢复

### 两个通道为什么必须分开

- **孔洞 / 槽**是布尔减出来的：只改了宿主面的 trim 内环，底层曲面没动 → `UntrimFace` 一步抹掉，
  孔壁面自动清理。实测 100×80×30 带 R6 通孔（7 面）→ 6 面 **240000**；
  带孔带槽（12 面）只取消孔 → 11 面 **224000**（槽完好保留）。
- **圆角 / 倒角**是过渡面：四边全被邻面共享，不是自由边，`UntrimOuterLoop` 直接返回 `null`。
  只能删过渡面 → 剩余面取 `UnderlyingSurface().ToBrep()` → `CreateSolid` 重缝。
  **必须整圈一起删**：10 面倒角盒只删 1 个圆角面会缝出变形面（9 面 74715.5），
  删全部 4 个才对（6 面 **75000**）。

### 边界（插件会直接在命令行告诉你，不藏）

- 同一宿主面上有多个孔时，取消其中一个会把该面**所有**内环一起恢复（Rhino API 边界）。
- 取消圆角是整件重缝，因此同件的孔/槽会被一并恢复。
  「只取消部分圆角、保留孔洞」需要孔体重放——几何路径已实测可行
  （毛坯 240000 → 重挖孔 236607.08），列入下一版。

### v1.3.2 修正：真半透明 + 蒙层不会"粘"在界面上

**半透明是真的了。** 之前是往不透明实体上叠一层高透明度灰，底色没变，看起来几乎没淡化；
现在用 `DisplayConduit.ObjectCulling` 把源对象本身从绘制里剔除，只画自己的两组子面——
锁定面是真玻璃壳（浅灰 0.72 透明），特征面是实心橙。

**蒙层不会残留。** 焦点状态下如果用别的手段改了实体、移动了它或把它删了，插件会自动收尾，
不用记着再运行一次 `FWSelect`。

## 0.1 前提与启动

- 已用 Yak 真安装：`特征识别工具 1.3.2.0`，位置 `…\packages\9.0\特征识别工具\1.3.2.0\`。
- **重开 Rhino**（装完必须重启，让新程序集替换旧的）。
- 与「基准面工具」是两个独立包，并存不冲突。

两种调用方式：

| 方式 | 操作 | 适用 |
|---|---|---|
| 字母菜单 | 命令行敲 `FW` → 回车 → 敲下划线字母 | 日常使用，一次看全所有功能 |
| 独立命令 | 直接敲 `FWRecognize` / `FWRepair` 等 | 熟练后更快，可被宏/脚本调用 |

入口命令：`FW` 或 `FeatureWorks`（两者等价）。

## 1. 第一次使用：识别一个实体

1. 在 Rhino 里准备（或导入）一个实体，例如一个带圆角、通孔、凹槽的方块。
2. 命令行敲 `FW` → 回车，屏幕列出字母菜单。
3. 敲 `A`（识别），提示"选择要识别的 B-Rep 实体"。
4. **点选那个实体** → 回车。

命令行的回报类似：

```
识别完成 / Done: 3 个特征  (faces=12, fillet=0, hole=1, cut=1)
```

含义：识别出 1 个孔、1 个槽（fillet=0 表示这个零件没有圆角）。识别结果（特征树）会**写进实体的 UserDictionary，随 .3dm 保存**，关掉重开文件仍在。

> 识别顺序是固定的三趟：先圆角链、再孔、最后拉伸切除（槽）。这符合"特征形成的逆序"——先剥掉最后加工的修饰，再挖掉主体负特征。

---

## 2. 看特征树：B 列表 / C 高亮

- 敲 `B`（`FWList`）：打印当前特征树，每项长这样：

```
[0] Hole_1      SimpleHole   faces=1   Radius=6, Depth=32
[1] ExtrudeCut_1 ExtrudeCut  faces=5   Depth=10
```

- 敲 `C`（`FWHighlight`）：再输入特征编号（如 `0`），对应的面会在视口里半透明高亮 + 黄线描边，直观看出"这个特征占哪几块面"。

这一步是后续所有操作的导航——先列表知道编号，再高亮确认，再决定抑制或重建哪一个。

---

## 3. 抑制一个特征：D

抑制 = 把某个特征从实体上"去掉"，恢复它加工之前的样子。

- 敲 `D`（`FWSuppress`）→ 输入特征编号。
- 内部动作：删掉该特征占用的面 → 补平面洞口 → 重新识别整棵树。
- 典型用途：把孔/槽"抹平"，得到一个更干净的基体。

命令行回报含 `solid=True` 和剩余面数；如果抑制后不再有该类型特征，说明成功。

---

## 4. 改参数重建：E

这是"参数化"的核心：改一个特征的参数，实体自动按新参数重算。

- 敲 `E`（`FWRebuild`）→ 输入特征编号 → 输入参数名 → 输入新值。
- 各特征可用的参数（用 `B` 列表能看到当前值）：

| 特征类型 | 可改参数 | 例子 |
|---|---|---|
| SimpleHole / CounterboreHole | `Radius`、`Depth` | R6 → R10 |
| ExtrudeCut（槽） | `Depth` | 10 → 18 |
| Fillet（圆角） | `Radius` | 3 → 5 |

- 例如把槽深从 10 改成 18：敲 `E` → 编号 `1` → 参数名 `Depth` → 值 `18`。
- 内部动作：先抑制该特征得到干净基体 → 用新参数重新做布尔切削。
- 实测：R6→R10 精确得到 R10；槽深 10→18 精确得到 18（不是 18.02，多余的布尔工具余量已被消除）。

> 如果参数名写错，命令会列出该特征"可用的 / available"参数，照着填即可。

## 5. 曲面原生/修剪证据：I（高级）

回答"这个曲面被做过什么操作"。不依赖识别是否成功，只要有实体就能分析。

- 敲 `I`（`FWEvidence`），或先选中一个实体再敲（未识别时它会从选中对象取几何）。
- 输出逐面报告，例如倒角盒：

```
faces=10 innerLoops=0 overhang=4 maxOverhangZ=3 reversed=0
  F1  NurbsSurface  loops=1 trims=4 overhangZ=3.00 hint=布尔/倒角修剪(trimmed)
  ...
  --- 加工史推断 / inferred operations ---
  * 4 个面的底层曲面比 trim 长最多 3 → 布尔工具有余量/倒角削过 trim
```

三个关键信号：

| 信号 | 含义 |
|---|---|
| `innerLoops > 1` | 面有内环 → 有孔或槽切入外表面 |
| `overhangZ > 0.5` | 底层曲面比 trim 长 → 被布尔切过或倒角削过 trim |
| `reversed` | 反向面 → 布尔减产生的内表面（孔壁/槽壁） |

原理：Rhino 的 B-rep 面 = 完整底层曲面 `UnderlyingSurface()` + trim 环。布尔减、打孔、倒角**只改 trim，不动底层曲面**。比较 domain 与 trim 边界的差，就能反推加工史。实测：槽侧壁 domain `20..31` / trim `20..30`，倒角侧面 domain `0..30` / trim `0..27`。

---

## 6. 整体修复还原毛坯：J（高级）

把实体上**所有已识别的特征一次性去掉**，还原成加工前的毛坯。

- 前提：先做第 1 步识别（`A`），有特征树。
- 敲 `J`（`FWRepair`）。
- 内部动作：删掉全部特征面 → 剩余面取底层原生曲面 `UnderlyingSurface().ToBrep()` → `Brep.CreateSolid` 重新缝合。
- 实测结果：

| 零件 | 删掉 | 还原结果 |
|---|---|---|
| 100×80×30 带孔带槽块 | 孔壁 + 槽内壁共 6 面 | 6 面尖角毛坯，体积精确 240000 |
| 同尺寸倒角盒 | 4 个 R3 圆角面 | 6 面尖角毛坯，体积精确 240000 |

> 为什么必须先"取回原生曲面"：带 trim 的面直接缝合会因孔口/槽口留洞而失败，只有恢复成完整解析面才能缝成实体。
>
> 边界说明：整体修复依赖"先识别出特征"。对没被识别的未知曲面不会自动还原——这是保守设计，避免误删几何。倒角面在 Rhino 里是 NurbsSurface 而非圆柱面，所以修复用的是识别引擎给出的特征面索引，不是按曲面类型猜。

修复后会话缓存会清空（毛坯已无特征树）。

## 7. 辅助命令

| 字母 | 命令 | 作用 |
|---|---|---|
| F | `FWTest` | 运行 9 项端到端自测，打印每项 PASS/FAIL |
| G | `FWClear` | 清除高亮与会话缓存（不动实体） |
| H | `FWStatus` | 查看当前目标对象、特征树、容差与各项特征 |

`FWTest` 的 9 项覆盖：孔识别、槽识别、孔抑制、孔径重建、槽深重建、圆角识别与抑制、特征树持久化、曲面证据、整体修复。全部 PASS 说明插件工作正常。

## 8. 常见问题

**Q：敲 FW 没反应？**
先确认已重开 Rhino（装完没重启），再用 `FWStatus` 看插件是否加载。从别处导入的实体要先点选。

**Q：识别不出圆角/槽？**
引擎针对"布尔减 / STEP 导入产生的标准特征"。自由曲面雕刻、非流形边、极薄壁不一定能识别。可先用 `I` 看证据，判断曲面有没有可识别的加工痕迹。

**Q：重建后体积不对？**
0.02 级别的偏差已修复（槽深现在精确）。若某特征参数组合导致布尔失败，命令会保留原实体而不是给你一个缺特征的坏结果。

**Q：保存重开后特征树还在吗？**
在。特征树写在 `Brep.UserDictionary`，随 .3dm 保存。重开后点选该实体、敲 `H` 可看到缓存会话为空但实体内的树仍在；重新 `A` 识别会读回同一棵树。
