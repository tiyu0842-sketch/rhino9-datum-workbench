# 特征识别工具 / RhinoFeatureWorks v1.3.2

Rhino 9 SolidWorks FeatureWorks 风格**特征取消**插件（独立包，与「基准面工具」并存）。

核心用途：倒完角 / 布尔完不满意，不想手工备份、重画——选中实体，插件识别出做过的特征，
把特征面亮橙、其余面半透明锁定，勾掉不要的，几何回到可再编辑的毛坯。

## v1.3 新增（本轮）

| 命令 | 作用 |
|---|---|
| `FWSelect` | **主入口**：点一个实体 → 识别 → 特征面亮橙、其余半透明（再运行一次关闭聚焦） |
| `FWFocus` | 只看当前两个通道的清单，不改显示 |
| `FWCancel` | 取消特征：选通道（Hole / Fillet / All）→ 选组号 → 执行；可连续取消 |
| `FWCancelPanel` | **取消面板**：圆角通道 / 孔洞通道两列，勾选后一键取消 |

## v1.3.2 修正（当前）

**① "其余面半透明" 之前其实是假的。** 原做法是往不透明实体上叠一层 0.85 透明的灰——底色没变，
看起来几乎没淡化。现在用 `DisplayConduit.ObjectCulling` 把**源对象本身从绘制里剔除**，
再画我们自己的两组子面：锁定面是浅灰 0.72 透明的真玻璃壳，特征面是实心橙。这样才真的能看穿内部。

**② 聚焦蒙层不会再"粘"在界面上。** 原来只有再运行一次 `FWSelect` 才能关掉；一旦源对象被别的命令
改了几何、被移动或被删，conduit 里缓存的面索引就和实体对不上，会留一层挪不走的橙色/灰色蒙皮。
现在有两道保险：

1. 挂 `RhinoDoc.ReplaceRhinoObject` / `DeleteRhinoObject` / `CloseDocument`（都是**静态事件**）——
   源对象一被替换或删除就自动收尾，不用记得再敲一次命令；
2. conduit 每次绘制前核对面数与包围盒中心，对象被移动或拓扑变了就停止绘制。

**两个通道背后是两套几何算法，不是实现取舍：**

- **孔洞通道**（布尔做出来的）：`Brep.UntrimFace(宿主面, tol)` 抹掉 trim 内环，孔消失，孔壁面自动清理。
  实测 100×80×30 带 R6 通孔（7 面）→ 6 面实体 **240000**；带孔带槽（12 面）取消孔 → 11 面 **224000**（槽保留）。
- **圆角通道**（过渡面做出来的）：`UntrimOuterLoop` 在实体圆角面上返回 `null`（外环边全被邻面共享），
  所以只能删过渡面 → 剩余面取 `UnderlyingSurface().ToBrep()` → `CreateSolid` 重缝。
  **必须整圈一起删**：10 面倒角盒只删 1 个圆角面 → 9 面 74715.5（错）；删全部 4 个 → 6 面 **75000**（对）。

已知边界（已写进命令输出，不藏）：
- `UntrimFace` 会抹掉该宿主面上的**所有**内环，同面多孔会一并恢复。
- 取消圆角是整件重缝，同件的孔/槽会被一并恢复。保留孔洞的圆角取消需要「孔体重放」，
  几何路径已实测可行（毛坯 240000 → 重挖孔 236607.08），列入下一版。

## 原有命令（v1.2 起）

- `FWPanel` —— 特征树停靠面板：列特征、点选高亮、改参数、一键整体修复
- `FW` / `FeatureWorks` —— 统一字母菜单入口
- `FWRecognize` 识别 · `FWList` 列表 · `FWTest` 9 项自测
- `FWHighlight` 高亮 · `FWSuppress` 抑制 · `FWRebuild` 参数重算 · `FWStatus` / `FWClear`
- `FWEvidence` 逐面曲面原生/修剪证据 · `FWRepair` 整体修复回毛坯

## 典型流程

```
FWSelect            ← 点实体，看橙色特征浮在灰毛坯里
FWCancelPanel       ← 或直接开面板勾选
  Hole   → 勾 Hole_1 → 取消     （只掉这个孔，槽保留）
  Fillet → 勾 Fillet_1 → 取消   （整圈圆角消失，回尖角毛坯）
Ctrl+Z                          ← 一次回到操作前（整段在一个 Undo 记录里）
```

## 技术要点

- AFAG 属性面邻接图 + 三趟洋葱剥皮识别
- 凹区判定基于几何不变量（有效法向 + bbox 投影极值），不依赖 OrientationIsReversed
- 槽深取真实 trim 边端点投影跨度，不受未修剪曲面 domain 干扰
- 特征树写入 Brep.UserDictionary，随 .3dm 持久化
- 曲面证据：B-rep 面 = 完整底层曲面 + trim 环；比较 domain 与 trim 边界反推孔/槽/倒角
- 聚焦显示：`DisplayConduit` + `Brep.DuplicateSubBrep` 分组绘制，**不改文档、不建对象、不进 Undo**；
  特征面画在 `DrawForeground`（`PostDrawObjects` 会被原实体深度剔掉，只剩线框）

## 面板

- `FWPanel` —— 识别 → 特征树 → 高亮/抑制/改参数重建
- `FWCancelPanel` —— 圆角通道 / 孔洞通道 → 勾选 → 取消；顶部「选实体并识别」直接从面板起步

## 菜单字母（FW 回车后）

A 识别 · B 列表 · C 高亮 · D 抑制 · E 重建 · F 自测 · G 清除 · H 状态
I 曲面证据 · J 整体修复
