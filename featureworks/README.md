# 特征识别工具 / RhinoFeatureWorks v1.6.1

Rhino 9 SolidWorks FeatureWorks 风格**特征取消**插件（独立包，与「基准面工具」并存）。

核心用途：倒完角 / 布尔完不满意，不想手工备份、重画——选中实体，插件识别出做过的特征，
把特征面亮橙、其余面半透明锁定，勾掉不要的，几何回到可再编辑的毛坯。

## v1.6.1（最新）：修复「取消一条倒角边后所有东西全部消失」

用户真机反馈后定位到 4 个缺陷，均为**失败/显示路径**，不是几何重建算法出错：

1. `FwFocusConduit.ObjectCulling` 无条件剔除源对象；一旦显示代理全部失效，
   就变成「源对象被剔除 + 自己什么都没画」= 视口全空 → 加 `HasDrawableContent()` 护栏，
   `Begin` 里无内容则禁用 conduit，**原模型照常显示**。
2. `TryApply` 把 `FwFocusSession.End(doc)` 写在失败 `return` 之后 → 失败时 conduit 仍在剔除
   → 改为「内存算完 + 校验通过才动文档」，`End` 移到 `Replace` 之前，失败/异常**不写文档、不关聚焦**。
3. `FWSelect` / 面板「选实体并识别」丢弃识别返回的 `CleanBrep`，用原始 brep 配清洗后的特征面索引
   （`MergeCoplanarFaces + Compact` 可能重排索引）→ 一律用 `clean ?? brep` 保证同源。
4. 写文档前无结果有效性校验 → 新增 `ValidateResult`（面数 / `IsSolid` / 体积量级 / 包围盒放大倍数），
   退化或异常放大的 Brep **拒绝写入并原文报出**，模型保持原样。

实测：编译 `105984 bytes / 0 error`；反射护栏空→False / 有内容→True；
纯几何回归 `7 面 / 63922.74 → 6 面 / 64000`；yak `74374 bytes`，已真安装到 `…\1.6.1.0\`。
**装完必须重开 Rhino 才生效。**

> 已知边界：单条 `BlendType.Chamfer` 平面斜切倒角目前识别为 **0 特征**（判据只认圆柱/NURBS
> 过渡面），不会出现在面板里；圆角（Fillet）不受影响。待扩展判据，不假装支持。

## v1.6 新增：常驻双向联动 + 严格两独立模块

用户三个问题的原话与对应答案：

| 你问的 | 真相（真机实测） | v1.6 做法 |
|---|---|---|
| 「为什么选了框之后只能在那个框里选，不能在原有界面上框选已标红的物体」 | `ObjectCulling` 剔除源对象后，conduit 画出来的橙色特征面只是**显示影子**、不是文档对象，Rhino 原生拾取够不到 | 常驻 `Rhino.UI.MouseCallback` 接管左键：视口直接点选 / 拖框 / Shift-Ctrl 加减选，conduit 画框选矩形与三态高亮；不建文档对象、不进 Undo |
| 「两边可以同时相互交互，而不是去选择那一边」 | v1.5 面板里有一段互斥清空，同一时刻只允许一边有勾选 | 删掉互斥，改成**一份 `FwSelectionState` 共享选中集**：视口 / 面板 / 两个模块共同读写 |
| 「分成两个模块：单独去除圆角、去除布尔；去布尔是不是必须先去完圆角」 | **不需要**。圆角盒 R3 `10 面 / 239315.06` + 1 孔 `11 面 / 235922.14` → 只删该孔内环 → `10 面 / 239315.06`，与纯圆角盒逐项一致 | **模块 A 去除圆角** / **模块 B 去除布尔切割** 两个独立执行器，任意顺序；按拍板「严格两模块、不要总开关」，删除「全部取消 → 回毛坯」按钮 |
| 「为什么不直接让面取消修剪还原，而是补那个面」 | 孔可以、圆角不可以：孔 = 底层曲面 + trim 内环；圆角 = 滚球扫出的**新增过渡曲面**，没有更大的底层曲面可还原（`UntrimOuterLoop` 在实体圆角面恒 null） | 模块 B 走 `Brep.RemoveHoles(指定 inner loop, tol)` 精确抹环；模块 A 只能删整圈过渡面 + 相邻面重缝 |

- **两个模块各按各的按钮**：模块 A「去除圆角（选中 N）」、模块 B「去除布尔切割（选中 N）」；
  只执行本模块通道里的选中项，另一模块的勾选原样保留；N=0 拒绝执行。
- **连带影响明确报出，不偷偷改**：模块 A 整件重缝会连带恢复同件孔/槽时，
  命令行与结果消息原文列出「原有 N 个内环 → 剩 M 个，另外 K 处布尔切割被一并恢复」，
  **不做孔体重放、不假装只取消了圆角**。
- **编号仍在**：模型上 `F1…/H1…` 标签与面板行一一对应，选中组青色粗线、悬停黄色描边。
- 命令行 `FWCancel` 同步改为两模块（去掉跨模块 `All`），优先沿用共享选中集。
- 新增文件 `FwSelection.cs`（共享选中集 + 常驻鼠标监听）；`FwFocusGroup` 增加 `Loops`（内环索引）、
  `FwGroupVisual` 增加 `Bounds`（框选投影用）。

> 以下 v1.5 及更早段落为**历史版本说明**，其中「孔洞用 UntrimFace」「圆角用 UntrimOuterLoop」
> 的旧描述已被 v1.6 的 E-024 实测推翻并更正，保留是为了看判断演化，不是当前实现。

## v1.5 新增：不再“flat”，编号对应 + 视口直接选边

用户的原话：「一个一个 flat，我都不知道这是哪个跟哪个」「我去选择边缘，然后取消它的特征不更好吗」。

- **视口逐组编号**：每个特征组在模型旁直接画 `F1/F2…`（圆角）、`H1/H2…`（孔洞）标签，
  面板每一行行首是**同一个编号**。不再靠猜“Fillet_7 究竟是哪一圈角”。
- **双向选择**：点面板行 → 视口把该组高亮（青色粗线），其余压暗；点面板的
  「视口拾取边/面」→ 回 Rhino 点边或面 → 反查所属特征组 → 面板对应行自动勾选。
  反查用 `ObjRef.GeometryComponentIndex`（`BrepFace` 直接查，`BrepEdge` 用 `BrepFace.AdjacentEdges()`）。
- **取消语义显式化**：`取消选中 N 项` / `保留全部（不改模型）` / `全部取消 → 回毛坯`。
  **一个都没勾时什么都不会删**（旧版“不勾=全部取消”太危险）。
- 新增命令 `FWPickFeature`（一般由面板按钮代跑，不必手敲）。
- 打包脚本不再覆盖 README / manifest，包内文档与源码同步。

## v1.4 新增：面板注册修复 + 两段式自动弹面板

**① 面板注册失败已修。** v1.3.2 里 `FWPanel` / `FwCancelPanel` 只有 `static readonly Guid PanelId` 字段，
但 Rhino 9 的 `Panels.RegisterPanel` 要求**面板类带类级 `[Guid(...)]` 特性**，
否则报 `type must have a GuidAttribute (Parameter 'type')`，面板根本注册不上。
v1.4 给两个面板类都加了 `[Guid]`，值与各自 `PanelId` 一致。

**② 两段式交互（参考 XNurbs 辅助面板）：** 敲 `FWSelect` → 点选对象（点选即"载入"，
不需要先把对象加进面板）→ 自动识别 → 视口高亮 + **自动弹出「特征取消」面板**，
面板列出识别到的特征并集（圆角通道 / 孔洞通道）。在面板里勾选即可剥离/抑制特征回毛坯。
省略了 v1.3 里"再单独敲一次 `FWCancelPanel`"那一步。面板若意外没弹出，仍可手动敲 `FWCancelPanel`。

## v1.3.2 修正（当前）

**① "其余面半透明" 之前其实是假的。** 原做法是往不透明实体上叠一层 0.85 透明的灰——底色没变，
看起来几乎没淡化。现在用 `DisplayConduit.ObjectCulling` 把**源对象本身从绘制里剔除**，
再画我们自己的两组子面：锁定面是浅灰 0.72 透明的真玻璃壳，特征面是实心橙。这样才真的能看穿内部。

**② 聚焦蒙层不会再"粘"在界面上。** 原来只有再运行一次 `FWSelect` 才能关掉；一旦源对象被别的命令
改了几何、被移动或被删，conduit 里缓存的面索引就和实体对不上，会留一层挪不走的橙色/灰色蒙皮。
现在有两道保险：

1. 挂 `RhinoDoc.ReplaceRhinoObject` / `DeleteRhinoObject` / `CloseDocument`（都是**静态事件**）——
   源对象一被替换或删除就自动收尾，不用记得再敲一次命令；
2. conduit 每次绘制前核对面数与包围盒中心，对象被移动或拓扑变了就停止绘制。

**两个模块背后是两套几何算法，不是实现取舍（v1.6 更正）：**

- **模块 B 去除布尔切割**（孔/槽）：底层曲面没动，只是宿主面多了 trim 内环。
  `Brep.RemoveHoles(IEnumerable<ComponentIndex>, tol)`（since 6.8）只删**指定的** inner loop。
  实测：盒+2孔 `8 面 / inner 4 / vol 233214.16` → 只删 H1 的 `[7,8]` →
  `7 面 / inner 2 / vol 236607.08`（H2 全留）；删两个孔 → `6 面 / inner 0 / 240000`。
  圆角盒 R3 `10 面 / 239315.06` + 1 孔 `11 面 / 235922.14` → 只删该孔内环 `[11,12]` →
  `10 面 / 239315.06`，**与纯圆角盒逐项一致，圆角完好**。
  `UntrimFace` 是旧版错误做法：官方定义「outer boundary is untrimmed AND all inner loops are removed」，
  会把同面所有孔一起抹掉。
- **模块 A 去除圆角**：圆角是滚球扫出的**新增过渡曲面**，四边与邻面共享，
  没有更大的底层曲面可还原；`UntrimOuterLoop` 官方要求外环边全 naked，对实体圆角面恒返回 `null`。
  只能删整圈过渡面 → 剩余面取底层原生曲面 → `CreateSolid` 重缝。
  **必须整圈一起删**：10 面倒角盒只删 1 个圆角面 → 9 面 74715.5（错）；删全部 4 个 → 6 面 **75000**（对）。

已知边界（v1.6 起写进命令输出，不藏）：
- 模块 A 整件重缝会连带恢复同件孔/槽的 trim 内环。按用户拍板「明确报出，不偷偷改」，
  结果消息会原文列出原有/剩余内环数与连带数，**不做孔体重放、不静默改回去**。
  （孔体重放几何路径已实测可行：毛坯 240000 → 重挖孔 236607.08，但本版不自动执行。）
- 模块 B 依赖识别阶段把孔洞组解析到 inner loop；若某组解析不到，执行器会明确报错而不是乱删。

## 原有命令（v1.2 起）

- `FWPanel` —— 特征树停靠面板：列特征、点选高亮、改参数、一键整体修复
- `FW` / `FeatureWorks` —— 统一字母菜单入口
- `FWRecognize` 识别 · `FWList` 列表 · `FWTest` 9 项自测
- `FWHighlight` 高亮 · `FWSuppress` 抑制 · `FWRebuild` 参数重算 · `FWStatus` / `FWClear`
- `FWEvidence` 逐面曲面原生/修剪证据 · `FWRepair` 整体修复回毛坯

## 典型流程（v1.6）

```
FWSelect            ← 点实体 → 自动识别 → 特征橙/其余半透明 → 自动弹面板
                       （同时挂上常驻视口监听，无需再点任何"拾取"按钮）
视口左键             ← 点选一个标红特征；或按住拖框一次选一片
Shift / Ctrl + 点选  ← 加减选；点空白 = 清空选中集
面板                 ← 两个列表与视口共享同一份选中集，F1/H1 编号与模型标签对应
  模块 B「去除布尔切割（选中 N）」→ 只删选中的孔/槽，圆角与其它孔全留
  模块 A「去除圆角（选中 N）」    → 整圈过渡面消失；若连带恢复孔，命令行原文报出
Ctrl+Z                          ← 一次回到操作前（整段在一个 Undo 记录里）
```

两个模块**可以任意顺序、可以都勾着**：执行时各取各的通道，互不牵连。

## 技术要点

- AFAG 属性面邻接图 + 三趟洋葱剥皮识别
- 凹区判定基于几何不变量（有效法向 + bbox 投影极值），不依赖 OrientationIsReversed
- 槽深取真实 trim 边端点投影跨度，不受未修剪曲面 domain 干扰
- 特征树写入 Brep.UserDictionary，随 .3dm 持久化
- 曲面证据：B-rep 面 = 完整底层曲面 + trim 环；比较 domain 与 trim 边界反推孔/槽/倒角
- 聚焦显示：`DisplayConduit` + `Brep.DuplicateSubBrep` 分组绘制，**不改文档、不建对象、不进 Undo**；
  特征面画在 `DrawForeground`（`PostDrawObjects` 会被原实体深度剔掉，只剩线框）
- v1.6 常驻选择：`Rhino.UI.MouseCallback` 接管左键 + `WorldToClient` 把每组世界包围盒投影成
  屏幕矩形做点选/框选命中；conduit 自绘面不是文档对象，靠 Rhino 原生拾取永远选不中
- v1.6 loop 级取消：`Brep.RemoveHoles(IEnumerable<ComponentIndex>, tol)` 只删指定的 inner loop，
  内环索引由 `BrepLoop.LoopIndex` + `BrepTrim.Edge.AdjacentFaces()` 在识别时解析

## 面板

- `FWPanel` —— 识别 → 特征树 → 高亮/抑制/改参数重建
- `FWCancelPanel` —— **模块 A 去除圆角** / **模块 B 去除布尔切割** 两个分区，
  各自一个执行按钮；与视口共享选中集；顶部「选实体并识别」直接从面板起步。
  「关闭聚焦 / 保留全部」只是不改模型地退出，不是取消总开关。
